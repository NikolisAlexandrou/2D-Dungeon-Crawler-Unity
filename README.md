# Dungeon Masters

A 2D dungeon crawler prototype built with Unity and C#. Players progress through connected combat and puzzle rooms, earning rewards before facing a dungeon boss.

## Gameplay

Clear each combat room to unlock the next area. Defeating all enemies spawns a reward chest and opens the exit, while puzzle rooms offer a different challenge between battles.

## Features

- Room-based enemy encounters
- Reward chests after clearing combat rooms
- Doors that unlock when room objectives are completed
- Puzzle rooms

## Technical Highlights

- Room progression that connects encounter completion, rewards, and door unlocking
- Enemy tracking to detect when a combat room has been cleared
- Combat and puzzle objectives within the dungeon progression

## Running the Project

1. Clone or download this repository.
2. Add the project through Unity Hub.
3. Open it using the Unity version specified in
   `ProjectSettings/ProjectVersion.txt`.
4. Open the main gameplay scene and press Play.
